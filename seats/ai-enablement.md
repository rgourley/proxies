## Cares about
- Connecting vendor data to internal AI tools through MCP or APIs, with no custom glue per team.
- Service credentials that do not belong to one person.
- Usage limits and costs that do not surprise anyone when many agents call at once.
- Controls on which internal staff and which tools can reach which data.

## Typical objections
- "Our agents can't log in with a personal user. Where is the service account?"
- "One key for the whole company is a non-starter. One key per rep is unmanageable."
- "What happens when an agent hits a plan limit mid-answer?"

## Questions this seat always asks
- How does a tool, not a person, authenticate?
- Can I see usage per tool and per team?

## Common failure mode
Designs for the agent and forgets the human who is accountable for what the agent did.
