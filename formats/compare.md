# Format: compare

Two versions, A and B, of the same artifact. One blind round, in parallel.

Each person writes:
- **Pick**: A, B, or neither.
- **Why**: from their seat. Cite specific differences between A and B.
- **What it would take from the other one**: the single best element of the version they did not pick.
- **Confidence**: 1 to 5.

Aim for about 250 words.

The facilitator randomizes which version is labeled A for each person, to remove order bias. It records the mapping in the run folder.

## Verdict
Every response starts with one line after the title: `**Verdict**: <Block | Rework | Ship with changes | Ship>. <one sentence on why>.` Block means you would stop it from your seat. Rework means it must change before you would use or approve it.

## Language
Plain business English. Name each step by what it does, in words. Never use diagram node letters or IDs. Explain acronyms the first time.
